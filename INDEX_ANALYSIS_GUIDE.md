## 🧠 Analysis Methodology (75 Years Experience)

Each index is scored using **6 Professional Factors**:

### 1. Trend Analysis (3 points)
- Moving averages (SMA20, SMA50, EMA12, EMA26)
- Uptrend vs Downtrend identification

### 2. Momentum (2 points)
- RSI (Relative Strength Index)
- Overbought/Oversold conditions

### 3. MACD (1 point)
- Bullish/Bearish crossover
- Momentum confirmation

### 4. Price Position (2 points)
- Distance from 52-week high/low
- Where in trading range

### 5. Volume Analysis (1 point)
- Volume trends
- Institutional activity

### 6. Recent Performance (1 point)
- Weekly momentum
- Short-term strength

**Total Raw Score**: Combined and normalized to 0-10 scale
